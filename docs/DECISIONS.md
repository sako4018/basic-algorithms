# Решения

Формат: дата — решение — причина — отхвърлено — последствие. По-старите решения за технологията са подробно в `../PLAN.md` → „Технология“.

## 2026-10-18 — Чист HTML/CSS/JS, без build
Причина: поправка = редакция + презареждане; Саркис трябва да може сам да отвори и оправи всеки файл. Отхвърлено: C# (Avalonia/Blazor), TypeScript, React/Svelte/Vue, Python (pygame/PyScript).
Последствие: без модули (работи от `file://`), глобални имена. Имената на уроците трябва да са уникални (проверено с grep, няма повторения).

## 2026-10-18 — Стъпките се изчисляват предварително
Причина: „Назад“ е безплатно, плейърът е прост, нов алгоритъм = един файл.
Последствие: уроците не пипат DOM; всяка стъпка носи пълното състояние (`bars`, `vars`, …).

## 2026-10-18 — Учителят води, не таймерът
„Напред →“ е главният бутон; „▶ Пусни“ е малък. Няма броячи, поле за масив и въвеждащ текст на екрана. Виж `TASTE.md`.

## 2026-10-19 — Пет езика в кода, JS е основният
Причина: желание на Саркис (по снимка). JS `code` е истината: стъпките сочат неговите редове, а другите езици имат `lineMap`.
Последствие: всяка промяна на кода изисква проверка на 6 езика (автоматично от валидатора). Фрагментите са без `#include`/`main`.

## 2026-10-19 — Паралелна работа с агенти в отделни worktree-та
Всеки агент в `.claude/worktrees/<клон>`, слива се в `master` един по един с `--no-ff` от координиращата сесия. Агентите пипат само своите файлове.
Последствие: остават стари worktree-та за чистене (T-12). `.claude/worktrees/` е в `.gitignore`.

## 2026-10-19 — Добавен е C#
Разделът C# е между C++ и Java, а кодът на всеки урок е като на Java (почти същият синтаксис), с `lineMap` само където Java има такъв. Причина: Саркис ползва C# в училище. Последствие: валидаторът изисква `csharp` във всеки урок. C# е единственият език, чийто код е пускан наистина (има .NET SDK).
