# Тестване

## Автоматични проверки
```bash
node tests/validate-lessons.js
```
Нужен е само Node (проверено с `/usr/local/bin/node`). Няма npm пакети. Скриптът зарежда всеки файл от `js/lessons/` и за 200 случайни масива на урок (с повтарящи се числа, подреден и обратно подреден масив) проверява:
- 8 стълба във всяка стъпка; `highlight` и `sorted` са валидни индекси;
- `lines` сочат реални редове във **всичките 6 езика** (след `lineMap`);
- `text` не е празен и няма „1 сравнения“/„1 размени“;
- сортиранията свършват със сортиран масив.

Изход 0 = всичко е наред, 1 = има проблеми (всеки е изписан).

Резултат на 19.10.2026: **ALL OK** за 12 урока (200 пускания на урок).

Какво **не** хваща: как изглежда на екрана, анимацията, правилността на самия обяснителен текст, и дали кодът на C/C++/Java прави същото като JS.

## Напредък и „Провери се“
```bash
node tests/test-progress-quiz.js
```
Без браузър. Проверява `js/progress.js` (празно хранилище, повторно маркиране, запазване след „презареждане“, развалени данни, блокирано хранилище) и `js/quiz.js` (последна стъпка, различни отговори, верният е текстът на следващата стъпка, всичките 12 урока по 20 случайни входа). Резултат на 19.10.2026: **ALL OK (около 42 600 проверки, броят варира със случайните входове)**.

## Код на C, C++ и Java (истинско пускане)
```bash
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk node tests/run-other-languages.js c
SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.4.sdk node tests/run-other-languages.js cpp
JAVA_HOME_TEST=<път до JDK/Contents/Home> node tests/run-other-languages.js java
```
За всеки урок добавя `main`, компилира, пуска и сравнява с независим JS резултат. Резултат на 19.10.2026: **ALL OK** за c, cpp и java (C/C++ с `-Wall` без предупреждения). Системата не е променяна: `SDKROOT` сочи към по-стар SDK, защото най-новият в Command Line Tools е счупен; JDK 21 (Temurin) е свален във временна папка, не е инсталиран.

## Ръчна проверка в браузър (Safari)
1. `open index.html`
2. За всеки урок: „Започни“ → „Напред“ до последната стъпка („Готово!“) → „Назад“ няколко пъти.
3. Във всеки раздел C / C++ / C# / Java / JS / Python свети точно един ред.
4. Светла тема (☀), „Нов масив“, плъзгач за скорост, Space и стрелки.
5. Конзолата на Safari е без грешки.

Последна пълна проверка: 19.10.2026, автоматично през DOM (AppleScript `do JavaScript`), 12 урока докрай, без грешки в конзолата. Външният вид на „Провери се“ е гледан на снимки (Safari) в тъмна и светла тема и при ширина 500 px; началният екран с 12 урока — на снимка в тъмна тема.

## Код на другите езици
- JS и Python: синтаксисът е проверен (`node --check`, `ast.parse`) за всички урока.
- C и C++: компилирани и пуснати (виж по-горе). В уроците е показан само алгоритъмът, без `#include`/`main`; тестът ги добавя.
- C#: кодът е компилиран и пуснат с .NET 8 SDK (`dotnet run`) във временен проект извън репото; изходът съвпада с JS за примерни входове във всичките 12 урока. Не е пускан на екрана на плейъра чрез `dotnet`, само сравнен.
- Java: компилирана и пусната с JDK 21 (виж по-горе).
