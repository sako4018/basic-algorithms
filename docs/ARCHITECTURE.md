# Архитектура

Проверено в кода на 19.10.2026 (клон `master`, commit `7851456`).

## Общ вид
Статичен сайт: HTML + CSS + чист JavaScript. Няма сървър, база данни, API, npm и build. Отваря се с двоен клик на `index.html` (`file://`), затова скриптовете са обикновени `<script>` тагове, без модули и без `fetch` на локални файлове.

```
index.html            две секции: #home-screen и #lesson-screen
css/style.css         стилове, черна тема (по подразбиране) и светла
js/lessons/*.js       по един урок = един глобален обект xxxLesson
js/player.js          рисува стъпка, Напред/Назад, Пусни, скорост, раздели за код
js/main.js            списък LEVELS, начален екран, навигация, тема
tests/                проверка на уроците (Node)
```

Редът на `<script>` в `index.html` има значение: уроците → `player.js` → `main.js`. `main.js` чете глобалните `xxxLesson` още при зареждане.

## Основна идея
Алгоритъмът **не се анимира сам**. Уроците изчисляват предварително списък от стъпки, а плейърът само показва стъпка по номер. Затова „Назад“ е просто предишната стъпка.

### Урок (`js/lessons/<име>.js`)
| Поле | Значение |
|---|---|
| `id`, `title`, `intro` | име; `intro` не се показва на екрана |
| `code` | редовете на JS кода (масив от низове) |
| `otherLanguages` | `{c, cpp, java, python: {code, lineMap}}` |
| `buildSteps(values)` | връща масив от стъпки |

### Стъпка
`{ bars, highlight, swapped, sorted, lines, vars, compares, swaps, text }`
- `bars` — числата в текущия им ред (дължина = брой стълбове)
- `highlight` — индекси, оцветени жълто (или червено, ако `swapped`)
- `sorted` — индекси, оцветени зелено
- `lines` — 1-базирани номера на редове от **JS** кода; за другите езици се превеждат през `lineMap`
- `vars` — таблицата с променливите; `text` — изречението под стълбовете
- `compares`, `swaps` — не се показват на екрана, ползват се във финалния текст

### Плейър (`js/player.js`)
- `openLesson(lesson)` → `useArray(случаен масив)` → `buildSteps` → `showStep(0)`.
- Стълбовете са постоянни елементи. `placeBars` ги съпоставя по стойност с новите позиции (`nearestUnplacedBar` при повтарящи се числа), затова размяната е плъзгане, а не прерисуване. Ако числата не съвпадат, стълбовете се създават наново.
- Цветове: класовете `highlight`, `swapped`, `sorted`.
- Кодът се оцветява с прост токенизатор (`CODE_KEYWORDS`).
- Състояние: само глобални променливи `player*` и `barItems`.

### Начален екран и навигация (`js/main.js`)
`LEVELS` описва 5 нива. Запис без `buildSteps` е заготовка („Скоро“, бутонът е изключен).

## Съхранение
Само `localStorage`: `theme` и `codeLanguage`. Достъпът е в `try/catch`. Напредък и тестове — още няма.

## Външни зависимости и интеграции
Няма (нито библиотеки, нито шрифтове, нито мрежови заявки). GitHub Pages още не е настроен.

## Ограничения
- Всички уроци ползват един и същ изглед със стълбове. Рекурсия със стек, графи и опашки изискват нов изглед (виж ROADMAP).
- Само един цвят за „готово“. Зеленото се ползва и за „текуща част“ в търсенето, min/max и сумата (виж T-01).
- Уроците никога не пипат DOM. Само `player.js` и `main.js` рисуват.
- Няма `lineMap` проверка по време на работа; проверява се от `tests/validate-lessons.js`.
