# Алгоритми стъпка по стъпка

Интерактивен визуализатор на алгоритми за ученици на 12–16 години. Учителят показва на проектор и минава през алгоритъма стъпка по стъпка: стълбовете се плъзгат при размяна, до тях е кодът (C, C++, Java, JS или Python) с осветен текущ ред и таблица с променливите.

## Как се пуска
Без инсталация. Отвори `index.html` в браузъра:

```bash
open index.html
```

## Управление
- **Напред →**, **Space** или **→** — следваща стъпка
- **← Назад** или **←** — предишна стъпка
- **▶ Пусни** — автоматично пускане (по избор)
- **Нов масив** — нови случайни числа
- плъзгач **Скорост на размяната** — надясно е по-бързо, наляво по-бавно
- раздели **C / C++ / Java / JS / Python** над кода — сменят езика (изборът се запомня)
- **☀** — светла тема (по подразбиране е черна)

## Уроци
- Проследяване на цикъл и условие
- Минимум и максимум (min и max)
- Сума и брой (sum и count)
- Линейно търсене (linear search)
- Двоично търсене (binary search)
- Сортиране чрез мехурчета (bubble sort)
- Сортиране чрез избор (selection sort)
- Сортиране чрез вмъкване (insertion sort)
- Сортиране чрез сливане (merge sort)
- Бързо сортиране (quick sort)
- Рекурсия: факториел и Ханойски кули (със стек от извиквания)
- Сравнение на сортирания (bubble sort и merge sort едно до друго)
- Стек и опашка (stack и queue)
- Обхождане в ширина (BFS) и в дълбочина (DFS)
- Най-кратък път (Dijkstra)

Планът за останалите уроци е в `PLAN.md`, а договореният вид — в `TASTE.md`.

## Файлове
```
index.html          начален екран и екран на урока
css/style.css       стилове (черна и светла тема)
js/main.js          списък с уроци, навигация, тема
js/player.js        общият плейър
js/lessons/         по един файл за всеки алгоритъм
js/views/           изгледи за стек, сравнение, опашка и граф
js/data/            общият граф
tests/              проверка на уроците (Node)
docs/               архитектура, задачи, план, решения, тестване
```

## Проверка
```bash
node tests/validate-lessons.js
```
Проверява стъпките на всички уроци и редовете на кода на петте езика. Нужен е само Node. Подробности — `docs/TESTING.md`.

Останалата документация: `docs/ARCHITECTURE.md`, `docs/TASKS.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md`.
