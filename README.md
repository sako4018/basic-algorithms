# Алгоритми стъпка по стъпка

Интерактивен визуализатор на алгоритми за ученици на 12–16 години. Учителят показва на проектор и минава през алгоритъма стъпка по стъпка: стълбовете се плъзгат при размяна, до тях е кодът (C, C++, C#, Java, JS или Python) с осветен текущ ред и таблица с променливите.

## Как се пуска
Онлайн: https://sako4018.github.io/basic-algorithms/

Или локално, без инсталация. Отвори `index.html` в браузъра:

```bash
open index.html
```

## Управление
- **Напред →**, **Space** или **→** — следваща стъпка
- **← Назад** или **←** — предишна стъпка
- **▶ Пусни** (става „⏸ Пауза“) — автоматично пускане (по избор)
- **↻ Нов масив** — нови случайни числа
- **? Провери се** — въпрос „Какво ще се случи на следващата стъпка?“ с 3 отговора (под управлението)
- плъзгач **Скорост** (под трите бутона) — надясно е по-бързо, наляво по-бавно
- клавишите Space, → и ← са показани като подсказка при задържане на мишката върху „Напред“ и „Назад“
- раздели **C / C++ / C# / Java / JS / Python** над кода — сменят езика (изборът се запомня)
- **☀** — светла тема (по подразбиране е черна)
- пройдените уроци се отбелязват с „✓ Пройден“ на началния екран (пази се в браузъра)

## Уроци
- Проследяване на цикъл и условие
- Минимум (minimum)
- Максимум (maximum)
- Сума (sum)
- Брой (count)
- Линейно търсене (linear search)
- Двоично търсене (binary search)
- Сортиране чрез мехурчета (bubble sort)
- Сортиране чрез избор (selection sort)
- Сортиране чрез вмъкване (insertion sort)
- Сортиране чрез сливане (merge sort)
- Бързо сортиране (quick sort)

Рекурсията, сравнението на сортирания и Ниво 5 (стек и опашка, BFS, DFS, Dijkstra) са махнати нарочно (19.10.2026). Планът е в `PLAN.md`, а договореният вид — в `TASTE.md`.

## Файлове
```
index.html          начален екран и екран на урока
css/style.css       стилове (черна и светла тема)
js/main.js          списък с уроци, навигация, тема
js/player.js        общият плейър
js/progress.js      запомня пройдените уроци
js/quiz.js          въпросите „Провери се“
js/lessons/         по един файл за всеки алгоритъм
tests/              проверки на уроците, на напредъка и на кода на C/C++/Java (Node)
docs/               архитектура, задачи, план, решения, тестване
```

## Проверка
```bash
node tests/validate-lessons.js
```
Проверява стъпките на всички уроци и редовете на кода на шестте езика (JS, C, C++, C#, Java, Python). Нужен е само Node. Още: `node tests/test-progress-quiz.js` (напредък и „Провери се“) и `node tests/run-other-languages.js c|cpp|java` (истинско пускане на кода). Подробности — `docs/TESTING.md`.

Останалата документация: `docs/ARCHITECTURE.md`, `docs/TASKS.md`, `docs/ROADMAP.md`, `docs/DECISIONS.md`.
